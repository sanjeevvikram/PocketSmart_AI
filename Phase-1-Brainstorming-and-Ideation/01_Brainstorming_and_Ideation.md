# Phase 1 – Brainstorming & Ideation

## Project Title

**PocketSmart AI – AI-Powered Smart Shopping and Budget Planning Assistant**

---

## 1. Problem Statement

Online shopping provides users with a large number of products and choices. However, users often find it difficult to select suitable products according to their budget, preferences, and requirements.

Users may also spend more than their planned budget because of unnecessary purchases or difficulty in comparing available options.

There is a need for a smart application that can understand a user's requirements and provide personalized shopping and budget-planning assistance.

---

## 2. Proposed Solution

PocketSmart AI is an AI-powered smart shopping and budget planning application.

The system helps users plan their purchases according to their budget and preferences. It provides recommendations for different categories such as home products, party items, and jewelry.

The application uses Artificial Intelligence to generate personalized recommendations while also providing a fallback catalog-based system when AI services are unavailable.

---

## 3. Target Users

The application is designed for:

- Students
- Working professionals
- Families
- Online shoppers
- Budget-conscious users
- Users who need help planning purchases

---

## 4. Main Idea

The main idea of PocketSmart AI is to combine:

- Artificial Intelligence
- Budget planning
- Product recommendations
- User preferences
- Category-based shopping assistance

The user provides requirements such as budget, style, and preferred items. The system processes these requirements and generates a suitable shopping plan.

## 5. Key Features

### User Authentication
- User registration
- User login

- Session management

### Smart Budget Planning
- User-defined budget
- Estimated spending
- Remaining budget calculation
- Category-wise allocation

### AI Recommendations
- Personalized recommendations
- AI-generated shopping plans
- Recommendations based on user preferences
- Different shopping categories

### Product Categories
- Home
- Party
- Jewelry
- Other expandable categories

### Fallback System
If the AI service is temporarily unavailable, the application can provide a catalog-based fallback recommendation.

### Web Application
- FastAPI backend
- Web-based user interface
- REST API
- SQLite database
